1. Initialization & Core Concepts

Always call mgraphics.init() in global scope for the main context. For offscreen contexts created with new MGraphics(w, h) you do not call init(). 
mgraphics.init();
mgraphics.autofill = 0;          // recommended
mgraphics.relative_coords = 0;   // or 1

function paint() {
  // your drawing code
}

// Force a redraw later:
mgraphics.redraw();

Properties

PropertyTypeDescription
autofill0 | 1If 1, stroke() also fills the path
relative_coords0 | 10 = pixel (top-left origin), 1 = relative (center origin)
size[w, h] (read-only)Current canvas size
autopaint / autosketch0 | 1Layer control (normally handled by init())
textfieldvisible0 | 1Show text field on click

2. Coordinate Systems

Absolute (relative_coords = 0)

  • Origin (0,0) = top-left
  • Y increases downward
  • Units = pixels

Relative (relative_coords = 1)

  • Origin (0,0) = center
  • Y = +1 top, Y = –1 bottom
  • X range depends on aspect ratio (left ≈ –aspect, right ≈ +aspect)
let [w, h] = mgraphics.size;
let aspect = w / h;   // useful in relative mode

6. Line Styles & Dashed Lines

Dashed lines are fully supported with set_dash.
set_dash(...dashes)
Alternating dash and gap lengths.
Call with no arguments to return to a solid line. 
mgraphics.set_dash(8, 4);          // 8 on, 4 off
mgraphics.set_dash(10, 3, 2, 3);   // complex pattern
mgraphics.set_dash();              // solid again
set_line_width(w) / get_line_width()
set_line_cap("butt" | "round" | "square")
set_line_join("miter" | "round" | "bevel")
get_line_cap() / get_line_join()

7. Text

select_font_face(name, "bold"?, "italic"?)
set_font_size(size)
font_extents() → [ascent, descent, height]
text_measure(str) → [width, height]

show_text(str)          // immediate draw (ignores matrix)
text_path(str)          // adds text outline to current path (transformable)
show_text is not affected by the current transformation matrix. Use text_path + fill/stroke when you need transforms.

8. Images & SVG

Images

image_surface_draw(image, source_rect?)
image_surface_draw_fast(image)          // no transforms

set_source_surface(image, dx?, dy?)
pattern_create_for_surface(image) → Pattern

SVG

// Quick
mgraphics.svg_render("icon.svg");
mgraphics.svg_render(svgObj, x, y, w, h, opacity);

// Better (cached + color remapping)
var svg = new MGraphicsSVG("icon.svg");
svg.mapcolor([0,0,0,1], [0.5,0.5,0.5,1]);
svg.mapreset();
mgraphics.svg_render(svg);

MGraphicsSVG properties: loaded, size, viewbox. Methods: setsvg(), mapcolor(), mapreset().

10. Offscreen Contexts

var off = new MGraphics(width, height);   // no init() needed
// draw into off exactly like the main context
var img = new Image(off);
mgraphics.image_surface_draw(img);

// or use as pattern
mgraphics.set_source_surface(img);
On HiDPI / Retina displays create the offscreen context at physical resolution (logical size × scale factor) and then scale the pattern down for sharp results.

12. Practical Tips for Performance

  • Prefer pre-rendered glyph atlases / offscreen bitmaps for dense grids (trackers, sequencers).
  • Use set_dash() instead of manually drawing dash segments.
  • Cache SVGs with MGraphicsSVG and reuse them.
  • Minimize path construction inside tight loops; reuse paths with copy_path / append_path when possible.
  • Call mgraphics.redraw() only when something actually changed.
  • For pure geometric dots, a small filled rectangle or ellipse is often faster than text.

Minimal complete example

mgraphics.init();
mgraphics.autofill = 0;
mgraphics.relative_coords = 0;

function paint() {
  let [w, h] = mgraphics.size;

  // background
  mgraphics.set_source_rgba(0.12, 0.12, 0.14, 1);
  mgraphics.rectangle(0, 0, w, h);
  mgraphics.fill();

  // dashed line
  mgraphics.set_source_rgba(0.9, 0.6, 0.2, 1);
  mgraphics.set_line_width(2);
  mgraphics.set_dash(6, 4);
  mgraphics.move_to(20, h/2);
  mgraphics.line_to(w-20, h/2);
  mgraphics.stroke();
  mgraphics.set_dash(0, 0);   // reset
}
